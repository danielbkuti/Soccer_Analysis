# Ederson First-Shot Concession Analysis

## Project Overview
Event-level analysis of goalkeeper Ederson Moraes examining how often goals are conceded from the first shot on target across Premier League seasons.

## Objectives
- Quantify first-shot concession frequency
- Analyze season-over-season trends
- Evaluate match outcome stability

## Tech Stack
- Python (pandas, numpy, matplotlib)
- PostgreSQL
- Jupyter Notebook
